# v0.9.0 Binary Intelligence Core — foundation slice

Implemented first:
- BinaryImage: immutable-style byte storage and safe file loading.
- BinaryView: bounds-checked little-endian reads.
- ValidationReport: initial generic input diagnostics.

This is a starter foundation, not yet the full 200-module roadmap. Format-specific validators, format mapping, IR, decoder integration and tests are subsequent milestones.
