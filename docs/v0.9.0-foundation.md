# v0.9.0 Binary Foundation (initial implementation)
- BinaryImage: byte-preserving input abstraction and safe file loading.
- BinaryView: bounds-checked little-endian accessors.
- Validation: diagnostic collection for basic input checks.
- Format engine slice: PE headers/COFF/optional header/sections/data directories; ELF program-header LOAD segments; basic Mach-O segment commands.
- Mapping helpers: PE RVA-to-file-offset and file-offset-to-RVA, image-base VA conversion.
- Embedded signature scan: PE, ELF, ZIP and GZIP signatures.

Limitations: this is a structural starter, not a complete/verified parser. ELF supports little-endian program headers only. Mach-O section detail, fat binaries, format-specific validations, nested payload extraction, and fuzzing remain future work. Mapping and scanning results are heuristic; offsets/signatures are evidence, not proof of embedded executable payloads.
